## 证件照排版工具 v1.0 完成

**用户需求**：日常开发场景下，做一个桌面小工具，用于证件照批量上传 → 缩放成指定尺寸（1寸/2寸/小1寸/小2寸） → 排版到 5寸/6寸 相纸上 → 加裁切线 → 导出到桌面。要求不损失清晰度。

**交付物**：
- `E:\WorkBuddy-space\证件照排版插件\index.html` — 单文件、零依赖、纯前端工具
- `E:\WorkBuddy-space\证件照排版插件\README.md` — 使用说明

**技术决策**：
- 选择"单 HTML 文件 + Canvas + 原生 JS"，不打包成 .exe
  - 用户场景：广告店日常用，单文件双击即用，比安装程序友好
  - 团队共享方便（丢到云盘或 U 盘即可）
- "导出到桌面"用 File System Access API（Chrome/Edge），其它浏览器回退到 download
- 清晰度方案：`canvas.imageSmoothingQuality = 'high'`，源图按原始分辨率 drawImage，仅做中心裁切，不重编码
- 排版计算：默认 1寸=3×3、2寸=2×2，跟用户要求一致

**关键实现细节**：
- 排版默认网格写在 `DEFAULT_COUNTS` 常量里（4 种尺寸各一组），用户改了不匹配会自动缩小
- 裁切线位置算法：`(cols+1) × (rows+1)` 个交叉点，每点画一个 len=4mm 的十字
- 多张相纸时文件名加 `_001`、`_002` 后缀
- 300 DPI 默认：6寸输出 1205×1797 px

**预留扩展点**（README 里也写了）：
- `DEFAULT_COUNTS` 改网格数
- `drawPhoto` 里加底色可换背景
- 想做 .exe 用 Edge "作为应用安装" 或 Tauri/Electron 打包

## v1.1 修改（用户反馈后的两个改动）

**改动 1：裁切线只画在画布外圈**
- 用户需求：去掉中间图片之间的裁切线，只在画布周围画，便于修边（参考图样式）
- 实现：删掉循环画 (cols+1)×(rows+1) 个十字，改成 4 角 L 形 + 4 边中点单标
- 删除了不再使用的 `drawCross` 函数

**改动 2：空位自动铺满**
- 用户需求：上传 1 张时所有位置都是这张；多张时空位自动填
- 实现策略：`idx < total ? photos[idx] : photos[total - 1]`，用最后一张填尾部空位
- 这样单张能铺满整页（用户核心场景），多张也合理（不会循环回开头让前几张重复出现）
- tip 文案 + README 同步更新

**学到的小细节**：
- 用户给的"严格按图样式" = 实际样板细节比口头描述更准确，先看图再实现
- "自动铺满"在中文场景里指"空位填满"，不一定是要 cycle 或复制首张——要明确用哪种

## v1.2 修改（裁切线样式修正）

**用户第三次澄清裁切线样式**：
- 不是 4 角 + 4 边中点的角标（v1.1 理解错了）
- 正确样式：**最外圈每张照片的边线向相纸边缘延伸**（顶行向上、底行向下、左列向左、右列向右），照片之间不画线
- 线起点在照片边的中点，一直伸到相纸边缘

**实现**：
- `drawCropLines` 重写：遍历网格，对 `r===0 / r===rows-1 / c===0 / c===cols-1` 的照片画延伸线
- 原 `cropLineLength`（长度）设置改为 `cropLineWidth`（粗细，默认 0.25mm）——长度已无意义（线固定到边缘）

**经验教训**：
- 用户两次口头描述 + 一张参考图，我对"裁切线样式"理解错了两次（先画网格十字→再画四角标）
- 教训：**让用户看图确认样式时，直接问"线从照片边的哪个位置出发？到哪结束？"**，一次问清楚，避免反复返工

## v1.3 修改（裁切线从角点出发，最终确认）

**用户确认**：线从照片边的**两端（角点）**延伸，不是中点。
- 顶行照片：从左上角、右上角各向上伸一条线到纸顶
- 底行照片：从两个底角各向下伸到纸底
- 左列照片：从两个左角各向左伸到纸左
- 右列照片：从两个右角各向右伸到纸右
- 角照片合计 4 条线（两个方向各 2 条），边照片 2 条，中心照片 0 条

**实现**：`drawCropLines` 用 `L/R/T/B`（照片四边像素坐标），对 `r===0 / r===rows-1 / c===0 / c===cols-1` 的照片画角点延伸线，一条 beginPath 内画两条线段再 stroke。

**结论（最终样式，已确认）**：照片间的网格线不画，只有外圈照片角点→相纸边缘的延伸线。

## 桌面快捷方式（2026-08-18 上午）

**用户需求**：桌面加快捷方式，方便快速打开工具。

**尝试过程**：
1. WScript.Shell COM 创建 .lnk → **被沙箱安全策略拦截**（"COM object instantiation can run arbitrary code"）
2. 改用 **.url 文件**（Internet Shortcut）→ 成功

**关键细节**：
- 桌面路径：`C:\Users\Administrator\Desktop`（[Environment]::GetFolderPath('Desktop') 获取）
- .url 文件内容：`[InternetShortcut]` + `URL=file:///...` + 可选 `IconFile`（Edge 图标）
- **中文目录名必须百分号编码**（用 python `urllib.parse.quote`），否则部分浏览器打不开：
  `证件照排版插件` → `%E8%AF%81%E4%BB%B6%E7%85%A7%E6%8E%92%E7%89%88%E6%8F%92%E4%BB%B6`
- 文件：`C:\Users\Administrator\Desktop\证件照排版工具.url`

**经验**：Windows 下创建快捷方式若 COM 被拦，.url 文本文件是零依赖的等效方案。

**⚠️ 但 .url 方案实际打不开（用户反馈"打不开"）**：
- 根因推测：`.url` 中**百分号编码的 file:// URL 被系统/浏览器双重解码**，路径变乱码 → 找不到文件
- 最终解决：改用 **GBK 编码的 .bat 批处理**（`start "" "E:\...\index.html"`），双击直接走系统关联程序打开文件，不经过 URL 解析 → **100% 可靠**
- 写法要点：`.bat` 含中文路径必须用 **GBK 编码**（中文 Windows cmd 默认 GBK 代码页），用 python `open(..., 'w', encoding='gbk', newline='')` 写，`newline=''` 防止 `\r\n` 变 `\r\r\n`；别用 UTF-8 写 bat
- 桌面文件：`C:\Users\Administrator\Desktop\证件照排版工具.bat`（旧 .url 已删除）
- 副作用：双击时 cmd 黑窗闪一下（正常现象，`exit` 立即关闭）

**桌面快捷方式最终结论**：Windows 沙箱里，PowerShell COM(.lnk) 被拦 → .url 双重解码打不开 → **GBK .bat 是最可靠的快捷方式方案**。
