# 证件照排版插件 - 项目记忆

## 项目目标
给图文广告店做一个日常用的证件照排版工具，单 HTML 文件，零依赖。

## 技术栈
- 纯前端：HTML5 + CSS3 + Canvas + 原生 JS
- 不打包：直接 `.html` 文件双击即用
- 浏览器能力优先：File System Access API（导出到桌面）、Clipboard API（粘贴图片）、Print API（直接打印）

## 关键约束（用户硬性要求）
1. **清晰度无损** — 源图按原始分辨率画到画布，仅做 cover 中心裁切，不重编码
2. **间距 1mm** — 这是默认参数，但 0–20mm 可调
3. **裁切线必须** — 样式按用户给的参考图：每个网格交点一个十字标记
4. **批量上传** — 拖拽/点击/粘贴三种方式
5. **导出到桌面** — Chrome/Edge 用 File System Access API，其它浏览器自动回退到下载
