# 证件照排版工具

零安装纯前端工具，单个 HTML 文件即开即用。

## 快速开始

**推荐浏览器：Chrome 或 Edge**（支持"另存到桌面"）

### 三种用法

| 方式 | 操作 | 适用场景 |
|------|------|----------|
| 直接双击 | 双击 `index.html` 用默认浏览器打开 | 临时使用 |
| 放到桌面 | 把 `index.html` 复制到桌面，下次双击 | 日常使用 |
| 团队共享 | 放到局域网共享文件夹或公司云盘 | 多台电脑共享 |

> ⚠️ 必须在 Chrome / Edge 中打开才能用"导出到桌面"；其他浏览器会自动回退到浏览器下载。

## 功能列表

| # | 功能 | 说明 |
|---|------|------|
| 1 | 批量上传 | 拖拽、点击、Ctrl+V 粘贴，三种方式 |
| 2 | 4 种照片尺寸 | 1寸 (25×35) · 小1寸 (22×32) · 2寸 (35×49) · 小2寸 (35×45) |
| 3 | 2 种相纸 | 5寸 (89×127) · 6寸 (102×152) |
| 4 | 自动排版 | 1寸→3×3 共9张 · 2寸→2×2 共4张 |
| 5 | 间距可调 | 1mm（默认），0–20mm 可调 |
| 6 | 裁切线 | 最外圈照片从朝外边的两端（角点）各延伸一条细线到相纸边缘，方便对齐裁切 |
| 7 | 自动铺满 | 上传 1 张照片自动复制到所有位置（"同款印多份"），多张时不够的位置用最后一张填 |
| 8 | 多页管理 | 上传超出单页数量，自动生成多张相纸 |
| 9 | 300+ DPI 导出 | 200 / 300 / 350 / 600 DPI 可选 |
| 10 | 矢量级清晰度 | 源照片以原始分辨率绘入画布，绝不损失清晰度 |

## 快捷键

| 键 | 功能 |
|----|------|
| `←` / `→` | 切换上一页 / 下一页 |
| `Ctrl + V` | 从剪贴板粘贴图片 |

## 操作流程

1. **上传**：把证件照拖到"上传区"，可以一次拖多张
2. **选尺寸**：左边选"几寸照片"和"几寸相纸"，右边实时预览
3. **调间距**：默认 1mm，按需调整
4. **导出**：点击"导出到桌面"，Chrome/Edge 会自动定位到桌面文件夹

## 输出规格（默认）

| 相纸 | 输出像素 @ 300 DPI |
|------|---------------------|
| 6寸 (102×152mm) | **1205 × 1797 px** |
| 5寸 (89×127mm) | 1052 × 1501 px |

如需更高清晰度，把 DPI 调到 600 即可。

## 典型场景

**场景 1：同款印多份**
1. 上传 1 张证件照
2. 选好尺寸和相纸
3. 直接导出 — 整张相纸会被同一张照片填满

**场景 2：不同照片混合**
1. 一次拖入多张证件照
2. 多出的位置按顺序自动填满（最后一张填尾部）
3. 超过一页会自动生成多张相纸

**Q: 源照片是横拍的，排进去后头像被切了？**
A: 工具默认按目标尺寸中心裁切（cover 模式）。建议先在 PS 或手机上把头像居中裁切好再上传。

**Q: 我要每张相纸排 8 张 1寸 怎么办？**
A: 当前版本固定 9 张（3×3）。改 `index.html` 里的 `DEFAULT_COUNTS['1寸']` 即可调整网格。

**Q: 想要彩色相纸背景（如红蓝渐变）？**
A: 在 `drawPhoto` 函数中用 `ctx.fillStyle = ...; ctx.fillRect(...)` 在照片下面铺一层即可。

**Q: 想做成 Windows 桌面 exe？**
A: 可用 Edge 的"将此页面作为应用安装"功能，或用 Tauri/Electron 打包。需要协助告诉我。
